# 황재민

여러 아이디어로 서비스와 게임을 만들며 소프트웨어 개발을 공부하고 있습니다.

## 프로젝트

### 데뷔 30초 만에

MediaPipe의 손·얼굴 인식을 활용한 웹캠 게임입니다.
현재 공개를 준비하고 있습니다.

### [Isolation](https://github.com/kingdoza/Isolation)

Unity 게임 팀 프로젝트입니다.
핵심 기능 기획과 게임 설정·인벤토리 구현을 담당했습니다.

### [Job Finder](https://github.com/alexcvbn/Job_Finder)

병역일터 채용공고를 수집하고, LLM으로 정보를 구조화해
알림으로 전달하는 Python 프로젝트입니다.
